# نظام متابعة المنتجات الكيميائية الحساسة

تطبيق مستقل مخصص لمتابعة المواد والمنتجات الكيميائية بالكيلوغرام (مثل Hydrosulfite، Soude caustique، Eau oxygénée، Acide acétique وبقية المنتجات المسجلة في النظام).

## الوظائف الأساسية
- تسجيل استلام المواد الكيميائية في أي وقت وبأي وتيرة (يومياً، أسبوعياً، شهرياً، أو عند وصول كل شحنة) مع إمكانية إدخال كميات عدة منتجات في عملية واحدة.
- تسجيل حركات الاستهلاك بشكل منفصل وتفصيلي مع تسجيل التاريخ، الورشة، والسبب.
- حساب إجمالي الوارد، المستهلك، والرصيد الفعلي التراكمي في كل تسجيل وبشكل فوري.
- منع أي حركة استهلاك أو حذف استلام قد يجعل رصيد المنتج سالبًا في أي وقت من التسلسل الزمني.
- إمكانية تعديل أو حذف أي حركة مسجلة مع تدقيق تلقائي فوري للأرصدة.
- تقرير شهري جاهز للطباعة المباشرة أو الحفظ كـ PDF، مع إمكانية تصدير البيانات إلى CSV.
- سجل تدقيق شامل لكل العمليات (إضافة، تعديل، حذف) في ورقة `Audit`.
- حماية الدخول برمز PIN مع جلسة خادمية مشفرة (`HttpOnly`) تدوم 8 ساعات دون الحاجة لإعادة إدخال الرمز عند تحديث الصفحة.

## البنية البرمجية
- `index.html`, `styles.css`, `app.js`: الواجهة الأمامية (HTML5 / Vanilla JS / CSS3).
- `api/inventory.js`: وسيط خادمي على Vercel (Serverless Function) لحماية التوكنات وأسرار الربط.
- `google-apps-script.gs`: سكربت Google Apps Script وقاعدة البيانات في Google Sheets.

## 1) إعداد Google Sheets
1. افتح جدول Google Sheets المطلوب بحساب Google الذي يملك صلاحية التعديل، ثم اختر `Extensions → Apps Script`.
2. استبدل محتوى المحرر كاملًا بمحتوى ملف `google-apps-script.gs` واحفظه.
3. في `Project Settings → Script Properties` أضف الخاصيتين التاليتين:
   - `WEBHOOK_TOKEN`: سلسلة نصية سرية عشوائية وطويلة.
   - `SPREADSHEET_ID`: معرّف جدول Google Sheets الخاص بك (اختياري، إذا لم تحدده سيستخدم المعرف الافتراضي المضمن في السكربت).
4. من `Project Settings` تأكد من ضبط المنطقة الزمنية المناسبة (مثل `Africa/Algiers`).
5. اختر `Deploy → New deployment → Web app`.
6. اضبط:
   - `Execute as` = `Me`
   - `Who has access` = `Anyone` (حتى يتمكن خادم Vercel من إرسال الطلبات بالرمز السري).
7. اضغط Deploy وانسخ رابط الويب المنتهي بـ `/exec`.

عند أول طلب ناجح، يُنشئ السكربت تلقائياً داخل الجدول الأوراق التالية دون المساس بأي بيانات سابقة:
`Products`, `Receipts`, `Consumption`, `Audit`.

## 2) إعداد Vercel
1. ارفع المشروع إلى مستودع GitHub جديد.
2. استورد المستودع في منصة Vercel.
3. في `Settings → Environment Variables` أضف المتغيرات التالية:
   - `CHEMICALS_WEBHOOK_URL`: رابط Apps Script المنتهي بـ `/exec`.
   - `CHEMICALS_WEBHOOK_TOKEN`: نفس قيمة `WEBHOOK_TOKEN` المحددة في Apps Script.
   - `APP_ACCESS_PIN`: رمز الدخول السري المخصص لمسؤولي المخزن.
   - `SESSION_SECRET`: سر تشفير عشوائي قوي (32 حرفاً أو أكثر).
4. أعد النشر (Redeploy) بعد حفظ المتغيرات.

## 3) طريقة الاستخدام
1. افتح رابط التطبيق وسجل الدخول برمز `APP_ACCESS_PIN`. تظل الجلسة نشطة لمدة 8 ساعات حتى مع تحديث الصفحة.
2. عند استلام أي شحنة مواد، افتح `Réception de stock` وسجل تاريخ الاستلام والمورّد والكميات المستلمة في أي وقت.
3. عند خروج كمية للاستخدام، افتح `Consommation` وسجل التاريخ، المنتج، الكمية، الورشة، والسبب.
4. لمتابعة الأرصدة، راجع `Vue d’ensemble` مع إمكانية التنقل بين الشهور من محدد التاريخ بالأعلى.
5. من صفحة `Historique et mouvements`، يمكنك تصفح كافة الحركات (حسب اليوم، الشهر، أو السنة)، مع إمكانية تعديل أو حذف أي حركة عند اللزوم.
6. من `Rapports`، يمكنك استخراج تقرير شهري قابل للطباعة أو تصديره إلى ملف Excel (CSV).

## قواعد الحساب
- Stock final = إجمالي الوارد التراكمي − إجمالي المستهلك التراكمي للمنتج حتى نهاية الشهر المحدد.
- ترتّب الحركات زمنياً، وتُحتسب الاستلامات قبل الاستهلاكات في نفس اليوم.
- يرفض النظام أي عملية استهلاك أو حذف استلام قد تؤدي إلى رصيد سالب في أي نقطة زمنية.

## تنبيهات مهمة
- النظام يعتمد على رمز PIN واحد؛ شاركه فقط مع الأشخاص المخولين بإدارة المخزن.
- لا تضع مفاتيح الربط أو الرموز السرية داخل الكود المصدري المكشوف في المتصفح.
- احتفظ بنسخة احتياطية دورية من جدول Google Sheets.
